# AskMyDocs.Web

Front-end em Angular do AskMyDocs. Veja o [README principal](../../README.md) para rodar o projeto completo.

```bash
npm install   # instala as dependências (o .npmrc usa legacy-peer-deps por causa de um bug do npm)
npm start     # http://localhost:4200, com proxy para a API em https://localhost:7135
npm test      # testes unitários (Vitest)
npm run build # build de produção em dist/
```
